# Soenneker.Quark.Gen.Presets

Options for the QuarkGenPresets generator. Extend as needed for your generator.

## Install

```bash
dotnet add package Soenneker.Quark.Gen.Presets
```

## What you get

- `GeneratorOptions` — Options for the QuarkGenPresets generator. Extend as needed for your generator.

## API at a glance

| API | What it does | Result / important behavior |
| --- | --- | --- |
| `GeneratorOptions.EmitDiagnostics` | Gets or sets a value indicating whether emit diagnostics. | Gets or sets a value indicating whether emit diagnostics. |
